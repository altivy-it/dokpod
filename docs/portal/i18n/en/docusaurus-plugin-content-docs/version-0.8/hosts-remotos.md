---
title: Remote hosts
description: Connect and revoke remote hosts with agent packages generated by the installer.
sidebar_position: 4
---

The installer generates an encrypted package with the agent and the identity
of each remote host. The installation needs `agentGrpcPort` in the answers: it
is the agents' gRPC port with mTLS, the only one published besides the edge.

## Add a host

```bash
sh install.sh host add --name host-b --engine podman     # docker, podman, or windows
```

- The package is written to `installDir/packages/<environmentId>.tar`, with
  `0600` permission, and contains `README.txt`, `agent.tar.enc`, and its
  SHA-256.
- The cipher passphrase is shown only once in the terminal. Without a terminal,
  it is written to `secretsDir/packages/<id>.passphrase`. Deliver it through
  another channel and delete the file.

On the target host:

1. Check the package: `sha256sum -c agent.tar.enc.sha256`.
2. Decrypt:
   `openssl enc -d -aes-256-cbc -pbkdf2 -iter 600000 -md sha256 -in agent.tar.enc -out agent.tar`.
3. Extract it and follow `README.txt`. On Docker and Podman it is a
   `docker compose up`; on Windows, the agent runs as a Windows Service.

The host shows up as connected within 5 minutes. The `status` command warns
about packages generated more than 7 days ago whose host has not connected.

## Revoke a host

```bash
sh install.sh host revoke --environment <id> --reason "host decommissioned"
```

The revocation is recorded in the audit log, and the API restarts to drop the
agent's active session. The other agents reconnect right after; the revoked
one does not come back.
